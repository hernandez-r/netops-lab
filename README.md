# NetOps Lab — Plataforma de gestión y monitoreo de redes

Un sistema para registrar equipos, redes y servicios; comprobar su disponibilidad; almacenar resultados históricos; visualizar alertas; y automatizar tareas de diagnóstico y administración en un laboratorio controlado.
![Diagrama netops](<img/netops-img.svg>)
*Arquitectura objetivo. Los componentes se incorporarán progresivamente; no necesitarás configurarlos todos al principio.*
